# 🍰 Cake Crush Bakery Website

## 📌 Project Description

This is a simple bakery website created using **HTML and CSS**.
It showcases different bakery products such as cakes and allows users to view pages like Home, About, Products, Cart, and Contact.

---

## 🌐 Pages Included

* Home Page
* About Page
* Products Page
* Cart Page
* Contact Page

---

## 🎨 Features

* Responsive navigation bar
* Product grid layout for cakes
* Contact form section
* Styled with warm bakery colors (pink, brown, cream tones)
* Simple and user-friendly design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Git & GitHub for version control

---

## 📷 Product Display

Products are displayed in a grid layout with images, prices, and an "Add" button.

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the folder in VS Code
3. Open `home.html` in a browser
4. Navigate through the pages using the menu
